本模块是 Thorium 项目的“构建变体与补丁”资源层，按目标平台和指令集维度组织：
- 顶层 `*.patch` 文件是对上游 Chromium/FFmpeg 源码的增量补丁，用于启用 HEVC/AC3 解码、修复 Wayland/WIN7 崩溃、调整策略模板、禁用隐私沙箱等，由上层构建流程在 `gn gen` 前通过 `apply_patches` 或类似机制应用。
- `AVX2/`、`AVX512/`、`CrOS/`、`Mac/`、`WIN7/` 等子目录各自包含一套 `*_args.gn` 构建参数文件（如 `AVX2_args.gn`、`mac_args.gn`、`cros_args.gn`），集中声明 `use_sse*`、`use_avx*`、`target_os`、`target_cpu`、`proprietary_codecs`、`enable_widevine`、`chrome_pgo_phase` 等 GN 变量，供不同发行版/指令集变体复用。
- `thor_ver_linux/wrapper-*` 是一组 Bash 启动包装器（wrapper-sse2、wrapper-avx2、wrapper-raspi、wrapper-sse3、wrapper-sse4），负责设置 `LD_LIBRARY_PATH`、`CHROME_DESKTOP`、`CHROME_VERSION_EXTRA`、`PROFILE`/`CACHE`、临时 profile 与安全模式等运行期环境，最终 `exec -a` 调用同目录下被替换占位符 `@@PROGNAME@@` 的实际二进制。
- `build_ffmpeg.py` 是独立的 Python 工具，封装 FFmpeg 的 `configure` + `make` 流程，按 `ARCH_MAP` 枚举 android/linux/mac/win 各架构，注入 NDK/MSVC/Xcode 交叉编译工具链，并在 `config.h`/`config.asm`/`ffbuild/config.mak` 上执行正则重写以适配 Chromium 的构建约束。
- 依赖方向单向向外：本模块仅产出配置与补丁，不引入 Chromium 源码；上层 build 系统负责选择对应 `*_args.gn` 并应用 `.patch`。
