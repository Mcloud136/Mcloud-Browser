运行前需设置 `CR_DIR`（Chromium 源码路径，默认 `C:/src/chromium/src`）和 `THOR_DIR`（MCloud/Thor 源码路径，默认 `%USERPROFILE%/mcloud`）。典型流程：`python win_scripts/trunk.py` 或 `tot.py` 同步上游 → `python win_scripts/setup.py [--woa|--avx512|--avx2]` 应用补丁与拷贝源码 → `python win_scripts/deploy_mcloud.py` 执行定点部署 → `gn gen out/mcloud --check` → `python win_scripts/build_win.py [jobs]` 构建。
