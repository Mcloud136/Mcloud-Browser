- 通过 optparse.OptionParser 定义命令行参数并以 --xxx dest=xxx 形式解析，对不支持的参数组合进行显式校验后退出。
- 使用全局模块级变量（_vs_version/_win_version/_vc_tools/_allow_multiple_vs_installs）在 main() 中初始化并在各函数间共享状态。
- 文件收集阶段先构建 (源路径, 归档相对路径) 的元组列表，再统一写入 zipfile，便于 dryrun 与 repackage 两种模式复用同一流程。
- 对多架构（x86/x64/arm64）采用重复但对称的配置字典（env_x86/env_x64/env_arm64）分别生成 SetEnv.cmd 分支与对应 .json 文件。
- 对外部工具（vswhere、reg query）的输出通过字符串标记（如 'installationPath: '、'KitsRoot10    REG_SZ    '）解析而非结构化格式。
