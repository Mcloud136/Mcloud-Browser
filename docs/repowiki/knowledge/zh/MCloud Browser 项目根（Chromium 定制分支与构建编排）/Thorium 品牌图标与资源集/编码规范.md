- 同一图标按平台与分辨率提供多份副本，例如 `product_logo_{8,16,22,24,32,48,64,128,256,512,1024,2048}.png` 覆盖常见尺寸需求。
- 平台相关资源严格按平台子目录隔离（`android/`、`mac/`、`win/`、`linux/`、`chromeos/`、`webui/`），避免跨平台命名冲突。
- 高分辨率图标使用 `@2x`、`@3x` 后缀（如 macOS `icon_16x16.png` 与 `icon_16x16@2x.png`），以适配 Retina 显示。
- 历史与过渡期资源通过独立目录归档（`OLD/`、`PRE_DPI_FIX_BACKUP/`、`STAGING/`），当前有效资源集中在 `NEW/`，便于构建时只选取最新素材。
