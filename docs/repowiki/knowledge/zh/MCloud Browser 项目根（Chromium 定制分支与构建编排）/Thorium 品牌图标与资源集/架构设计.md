该模块为纯静态资源目录，按目标平台与用途分层组织：
- `NEW/`：自 M100 起启用的主资源集，按平台子目录划分（`android/`、`chromeos/`、`linux/`、`mac/`、`win/`、`webui/`、`mcloud_shell/`、`mcloud_debug_shell/`），每个平台内部再按分辨率或用途细分（如 Android 的 `drawable-*dpi`、macOS 的 `gen/app`/`gen/document` 多尺寸 PNG 以生成 `.icns`）。
- `STAGING/`：测试、草稿、暂存与上传用图，不直接参与构建。
- `OLD/`、`PRE_DPI_FIX_BACKUP/`：历史版本与 DPI 修复前的备份，用于回溯旧版 Logo。
- 根目录：通用 SVG/PNG（如 `product_logo.svg`、`chromium_logo.svg`、`mcloud.svg`）以及 ASCII 艺术文本与许可证文件（`APACHE_LICENSE.txt`）。
本模块不包含可执行代码，仅作为构建系统与其他模块的资源输入，依赖方向单向——其他模块引用此目录中的资源，本模块不依赖项目其余部分。
