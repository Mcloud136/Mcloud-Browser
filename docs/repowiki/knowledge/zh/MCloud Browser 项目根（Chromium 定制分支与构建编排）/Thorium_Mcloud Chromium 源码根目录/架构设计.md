该模块是 Chromium 源码树的根（src/），采用按功能域划分的子目录结构：chrome/ 存放浏览器应用层（含 android/app/browser/common/installer 等）；components/ 提供可复用的功能组件；content/ 封装渲染进程与内容宿主；ash/ 为 ChromeOS 桌面外壳；media/net/sandbox/services/ui/v8/third_party/tools 分别对应媒体、网络、沙箱、服务、UI、V8 引擎、第三方依赖与工具链。构建系统以 GN 为核心，根 BUILD.gn 通过 import 各 build/config/*.gni 并声明 thorium / thorium_all / gn_all 等聚合目标，将 //chrome:chrome 作为默认产物，同时根据 is_win/is_linux/is_mac/is_android/is_chromeos 条件化引入平台特定目标（如 mini_installer、mac、linux stable）。入口点 chrome/app/chrome_main_delegate.cc 实现 ChromeMainDelegate，负责进程生命周期、用户数据目录、FeatureList/Mojo/Ozone 初始化以及 MCloud 特有的 mcloud_flags.txt 启动参数注入。自定义特性开关集中在 chrome/browser/mcloud_flag_entries.h，通过 SINGLE_VALUE_TYPE/FEATURE_VALUE_TYPE/MULTI_VALUE_TYPE 宏注册到 chrome://flags。安装器位于 chrome/installer/linux(debian/rpm)、chrome/installer/mini_installer 等，配合 chrome/install_static 完成跨平台打包。
