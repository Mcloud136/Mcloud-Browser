本模块是 Chromium 源码树外的 ARM 架构适配层，通过三类构件组织不同目标平台：
- 构建参数文件（*.gn）：`raspi/raspi_args.gn` 定义 Linux arm64 + Raspberry Pi 专用开关（`is_raspi=true`、`arm_tune=cortex-a72`、VA-API、Widevine 等），`win_ARM_args.gn` 定义 Windows on ARM 构建（`target_os=win`、`is_win_arm64=true`、PGO phase 2），`android/` 下按 `arm32_args.gn` / `arm64_args.gn` / `x86_args.gn` / `x64_args.gn` 分别给出 Android 各 ABI 的完整 gn 变量集。
- 平台 gni 覆盖：`woa_arm.gni` 与 `mac_arm.gni` 通过 `current_cpu`/`v8_current_cpu` 分支声明 `arm_version`、`arm_arch`、`arm_fpu`、`arm_control_flow_integrity` 等底层编译参数，并按 arm/arm64 区分 NEON、Thumb、PAC/BTI 策略。
- 平台补丁与依赖：`raspi/` 包含 WideVine 二进制补丁（`libwidevinecdm_patched.so`、`widevine_fixup.py`、`netflix.patch`、`widevine-other-locations.patch`）、RPM 安装模板 `chrome/installer/linux/rpm/mcloud.spec.template` 以及 remoting 安装器片段；`third_party/` 提供 libaom、libvpx、libyuv、widevine、xnnpack 的 ARM 适配源。
- 部署脚本：根目录 `setup_arm.sh` 将 `build/`、`media/`、`third_party/` 复制到宿主 Chromium 源码树对应位置，配合 `args.list` 完成一键注入。
依赖方向单向指向 Chromium 构建系统：本模块不引入运行时代码，仅通过 gn/gni 变量和补丁文件影响上游构建流程。
