模块以 PowerShell 脚本为入口层，按 KPI 维度拆分为独立可执行脚本：`bench_startup.ps1`（K1 冷启动）、`bench_memory.ps1`（K2 内存峰值）、`bench_size.ps1`（K7 二进制体积），并由顶层 `run_baseline.ps1` 编排三者一键执行，统一生成 Markdown 报告写入 `docs/dev-logs/`。各脚本通过 `Start-Process` 启动被测 `chrome.exe`，使用全新临时用户数据目录隔离运行环境，并以中位数统计多次采样结果。`tools/` 子目录存放辅助工具：`check_features.py` 解析 `mcloud_flags.txt` 并在上游 Chromium 源码树中检索 feature 标识符是否仍有效；其余 `.ps1` 脚本（`bolt_pipeline.ps1`、`pgo_collect.ps1`、`diag_igpu_green_screen.ps1`、`verify_builtin_flags.ps1`）分别支撑 BOLT 链接优化、PGO profile 采集、核显绿屏诊断与内置标志验证。依赖方向单向：编排脚本 → 指标脚本 → 系统 API / Chromium 进程；Python 工具仅依赖标准库，不反向依赖 PowerShell 脚本。
