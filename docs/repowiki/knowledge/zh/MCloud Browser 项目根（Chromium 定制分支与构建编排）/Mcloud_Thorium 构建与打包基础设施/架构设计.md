该模块是 Thorium/Mcloud 浏览器的构建与分发支撑层，按目标平台与用途划分为若干子目录：
- 顶层 gn_args.list / args.list / win_args.list / win_gn_args.list 通过 `gn args` 生成全量 GN 参数清单，配合根级 args.gn 完成 Chromium 的编译开关定制；BUILDER 文件记录沙箱权限、Polly/LLVM 优化与 AVX-512 禁用等构建笔记。
- DEBUG/ 集中所有调试相关 *.gn 文件（debug_args.gn、mac_ARM_debug_args.gn、win_debug_args.gn 等）和 build_debug_*.sh 脚本，用于生成带 UI Debug Shell 的可调试产物。
- Flatpak/com.mcloud.browser/ 使用 CroFT 管理 patches/all.json 中声明的 chromium/ffmpeg 补丁，并通过 build-aux/bootstrap.sh/build.sh/install.sh 在 Flatpak 沙箱内构建；同时包含 org.chromium.Chromium.yaml、metainfo.xml、desktop 文件及 GTK/Widevine/Kerberos 等运行时配置。
- Arch_Linux/ 提供 PKGBUILD/.SRCINFO/mcloud-browser.install/shell 包装器，从官方 .deb 提取并安装到 Arch 仓库。
- APPIMAGE/ 基于 pkg2appimage 与 Thorium.yml 将 .deb 重打包为 AppImage，files/ 提供图标与 mcloud-shell 入口。
- portable/ 提供 THORIUM-PORTABLE/THORIUM-SHELL 启动脚本、C 源码 THORIUM-PORTABLE.sh.x.c、以及 make_portable_linux.sh / make_portable_win.py / make_portable_win.sh 分别生成 Linux zip 与 Windows 便携包。
- hangout_services/ 是内置的 Google Hangouts 组件扩展（manifest.json + thunk.js），默认通过 enable_hangout_services_extension 开关集成。
- default_apps/default_extensions.json、mcloud_strings.grd、google_api_keys-inc.cc、ulimit.conf、widevine_versions.txt 等提供默认扩展、本地化字符串、API Key 注入、系统 ulimit 与 WideVine 版本管理等辅助资源。
依赖方向单向：各平台打包脚本仅依赖上游 Chromium 构建产物（.deb 或 out/ 目录），不反向依赖业务代码。
