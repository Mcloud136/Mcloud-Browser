# --- Video Decode Fix (2026-08-21, 实测定位；注释更正 2026-10-08) ---

# 禁用后回退 D3D11VideoDecoder，核显场景实测绿屏消失，硬解能力不受影响。
# 事实更正：上游 M151 基线该 feature 默认为 DISABLED_BY_DEFAULT（见源码树
# git diff 审计），本仓库 src/media/base/media_switches.cc 覆盖将其启用，
# 此处运行时再禁用 —— 二者互相抵消。下次升级清理：移除覆盖文件中该定制
# 后可删除本行禁用（进度见 docs/progress.md 4.5 与缺陷档案）。
