- 每个目标平台以独立的 *.gn 文件集中声明 target_os/target_cpu/v8_target_cpu 及完整 gn 变量集，便于通过 --args-file 切换构建配置。
- gni 文件统一通过 `if (current_cpu == "arm" || v8_current_cpu == "arm")` 与 `else if (current_cpu == "arm64" ...)` 分支声明 arm_version/arm_arch/arm_fpu/arm_tune 等底层参数，并对 arm64 设置 PAC/BTI 控制流完整性。
- 所有发布型构建统一开启 `is_official_build=true`、`enable_stripping=true`、`symbol_level=0`、`thin_lto_enable_optimizations=true`、`enable_rust=true` 以获得最小体积与最佳性能。
- 多媒体能力通过成组开关启用：`media_use_ffmpeg=true`、`media_use_libvpx=true`、`enable_hls_demuxer=true`、`proprietary_codecs=true`、`ffmpeg_branding="Chrome"`，并配套打开 H.265/Dolby Vision/AC-4/DTS 等平台编解码选项。
- WideVine 相关构建统一启用 `enable_library_cdms=true`、`enable_widevine=true`、`enable_media_drm_storage=true`，并通过 `ignore_missing_widevine_signing_cert=true` 绕过签名证书检查。
- Android 构建在 `android/` 子目录下按 ABI 拆分 gn 文件（arm32/arm64/x86/x64），并在文件名中体现目标 CPU，同时固定 `system_webview_package_name` 与 `trichrome_library_package` 为 mcloud 品牌包名。
