- 所有平台构建均通过 `CR_DIR` 环境变量指向 `chromium/src`，默认 `$HOME/chromium/src`
- GN 构建输出目录统一为 `out/mcloud`，Windows 发布产物命名为 `mcloud_{版本}_win64_mini_installer.exe`
- 运行时优化标志集中维护于 `mcloud_flags.txt`，由内置加载器在浏览器启动时注入，用户命令行参数优先级更高
- 平台差异通过 `arm_builds`、`other_patches`、`infra_packaging` 中的 `.gn/.gni` 与补丁文件按 flag 选择性覆盖，而非 fork 独立源码树
- 基准验证统一走 `benchmark/` 下的 PowerShell/Python 脚本，构建后必须执行 `verify_builtin_flags.ps1` 确认 flags 注入
