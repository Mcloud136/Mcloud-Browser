- 每个平台打包目录（Arch_Linux、Flatpak、APPIMAGE、portable）均自包含 README 说明与独立构建脚本，使用者只需在该目录下执行对应脚本即可完成打包。
- Shell 脚本统一采用 ANSI 彩色输出（YEL/RED/GRE/c0/bold/underline 变量）与 yell/die/try 错误处理封装，并在开头支持 --help 参数。
- GN 构建参数以 .list 文件形式通过 gn args 导出，infra 内维护多份清单（args.list、gn_args.list、win_args.list、win_gn_args.list）区分基础参数与平台特定参数。
- Flatpak 补丁通过 patches/all.json 集中声明，按 chromium/ 与 ffmpeg/ 子目录分类，便于 CroFT 批量应用与追踪来源。
- 调试相关 *.gn 文件按平台拆分（debug_args.gn、mac_ARM_debug_args.gn、mac_x64_debug_args.gn、win_debug_args.gn、test_build_args.gn），由 DEBUG/ 下的脚本选择加载。
- 可执行二进制（如 chrome-sandbox、cgpt）在安装阶段通过 install 命令设置 4755 权限，确保 setuid 沙箱正常工作。
