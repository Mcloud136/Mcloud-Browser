- 生成 GN 参数清单：运行 `gn args --list` 后由 infra 内的脚本整理为 args.list/gn_args.list/win_args.list。
- 调试构建：进入 infra/DEBUG 执行 build_debug_linux.sh / build_debug_shell_linux.sh / build_debug_win.sh，产物位于 //out/mcloud/Mcloud Browser_UI_Debug_Shell。
- Flatpak 构建：需先安装 CroFT，再在 Flatpak/com.mcloud.browser 下通过 build-aux/bootstrap.sh 准备环境，build.sh 打补丁并构建。
- Arch 打包：在 Arch_Linux 目录执行 `makepkg -si`，会下载对应版本的 .deb 并打包为 AUR 包。
- AppImage：将 .deb 放入 infra/APPIMAGE 后运行 ./make_appimage.sh，依赖 pkg2appimage 与 Thorium.yml。
- 便携包：Linux 端运行 portable/make_portable_linux.sh [--arm]，Windows 端运行 portable/make_portable_win.py 并确保 7z 路径在 PATH 中。
