Windows 上需在干净 VM 中安装 VS 2019/2022 并勾选 Desktop development with C++、VC MFC (x86/x64)、VC ARM64 编译器及 Windows SDK Debuggers；然后在 depot_tools/win_toolchain 目录下执行 `python3 package_from_installed.py 2019|2022 -w <SDK版本>`（例如 `-w 10.0.20348.0`）生成工具链 zip。depot_tools 自身可通过 `./update_depot_tools`（Linux/Mac）或 `update_depot_tools.bat`（Windows）手动更新，或通过设置 DEPOT_TOOLS_UPDATE=0 禁用自动更新。
