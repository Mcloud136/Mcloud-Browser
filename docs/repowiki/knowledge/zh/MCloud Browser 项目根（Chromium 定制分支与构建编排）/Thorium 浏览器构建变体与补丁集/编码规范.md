- 每个目标平台/指令集变体以独立目录存放，并以 `<variant>_args.gn` 命名 GN 参数文件，集中声明 `use_sse*`、`use_avx*`、`target_os`、`target_cpu` 等开关。
- Linux 启动包装器统一命名为 `wrapper-<simd>` 形式，通过环境变量（`LD_LIBRARY_PATH`、`CHROME_DESKTOP`、`CHROME_VERSION_EXTRA`、`PROFILE`、`CACHE`）和命令行解析（`--temp-profile`、`--safe-mode`）在 `exec` 前注入运行期参数。
- 所有 Linux wrapper 共享相同骨架：检测 xdg 工具、清理旧 crash report、读取 `$XDG_CONFIG_HOME/mcloud/mcloud-flags.conf` 追加用户 flags，最后 `exec -a "$0" "$HERE/@@PROGNAME@" $CHROME_USER_FLAGS "$@"` 执行实际二进制。
- 补丁文件采用 GNU diff 格式且文件名以 `fix_`/`add_`/`mcloud_`/`disable_` 等前缀描述变更意图，便于上层按功能域筛选应用。
- `build_ffmpeg.py` 通过 `RewriteFile` 对 `config.h`/`config.asm`/`ffbuild/config.mak` 执行正则替换来强制关闭/开启特定宏与链接选项，避免直接修改上游源码树。
