仓库以 `src/` 下的 Thorium/Mcloud Chromium 定制源码为核心，围绕其提供多套构建入口：Linux/macOS 由 `build.sh`/`autobuild.sh`/`setup.sh` 驱动，Windows 由 `win_scripts/deploy_mcloud.py` + `build_win.sh` 驱动；所有路径最终都指向 `depot_tools` 提供的 `gclient sync`、`gn gen`、`autoninja` 流水线。`arm_builds`、`other_patches`、`infra_packaging` 通过 `setup.sh` 的 `--mac/--raspi/--android/--cros/--avx2/--avx512` 等 flag 向 `chromium/src` 注入对应平台的 `.gn/.gni`、第三方库与补丁；`pak_tool` 在 setup 阶段预编译为 `out/mcloud/pak` 供资源打包使用；`benchmark` 在构建后校验内置 flags 注入与 KPI；`logos_assets` 被各平台包装脚本引用生成安装包图标。发布流程统一收敛到 README 描述的 `autoninja -C out/mcloud chrome mini_installer` 产物命名规范，并通过 GitHub Actions 打 tag 后上传 Release。
