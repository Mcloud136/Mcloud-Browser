- 每个脚本定义统一的 `fail(msg)` 与 `try_run(command)` 辅助函数，通过 `subprocess.run(..., shell=True, check=True)` 执行命令并在失败时打印带脚本名的错误信息后以 exit code 111 退出。
- Chromium 源码路径通过 `os.getenv('CR_DIR', r'C:/src/chromium/src')` 读取，MCloud 源码路径通过 `os.getenv('THOR_DIR', ...)` 读取，避免硬编码绝对路径。
- 命令行帮助通过检测 `--help` 参数并调用 `display_help()` 输出用法说明后 `sys.exit(0)`。
- 补丁文件集中声明在列表（如 `patches = [...]`）中，再遍历调用 `git apply --reject`，便于启用/禁用单个补丁。
- 架构变体（WOA、AVX512、AVX2）通过 `if '--flag' in sys.argv` 分支分别调用独立的 `copy_*` 函数，保持各目标配置的代码隔离。
- 路径拼接统一使用 `os.path.normpath(os.path.join(...))` 确保跨平台路径正确性。
